AUTOCARE - VEHICLE SERVICE & MAINTENANCE MANAGEMENT SYSTEM

Technology:
- HTML5
- CSS3
- JavaScript
- Browser LocalStorage

HOW TO RUN:
1. Extract the ZIP file.
2. Open index.html in Google Chrome, Microsoft Edge, or Firefox.
3. Click Get Started.
4. Login using any valid email and a password with at least 4 characters.
5. Add a vehicle.
6. Add services, reminders, expenses and service centers.
7. Open Reports to see calculated statistics.

No npm, Node.js, MySQL, XAMPP or server is required.

DATA:
All project data is stored in the browser's LocalStorage. Data remains after refreshing the page in the same browser.
To clear all project data, use browser DevTools -> Application -> Local Storage and remove keys beginning with "autocare_".
